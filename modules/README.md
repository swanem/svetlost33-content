# Kanonski moduli

Ovaj direktorijum će sadržati uredničke izvore modula `library`, `cycles`,
`calendar-YYYY` i `backgrounds`. I0–I2 namerno ne rastavljaju potpisani r1:
njegovi bajtovi ostaju u `releases/legacy/annual-2026-r1`, a zamrznuti M0 v2
fixture pokazuje buduću modularnu granicu bez proglašavanja novog produkcionog
izdanja. Prvi stvarni modularni izvoz nastaje tek uz novi pregled i release-set.
